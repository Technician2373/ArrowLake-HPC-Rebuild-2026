# Arrow Lake HPC Dependency & Toolchain Setup

This document contains the full package installation script used to prepare a fresh Ubuntu 26.04 system for Arrow Lake HPC development, kernel building, Mesa/Vulkan/SPIR-V compilation, oneAPI HPC toolkit installation, and system debugging.

The script installs:

- Core build tools  
- Networking & diagnostics  
- System monitoring tools  
- Filesystem & disk utilities  
- Text/search utilities  
- Editors & shells  
- Programming languages  
- Graphics & GPU tools  
- Kernel development toolchain  
- Debugging & tracing tools  
- Compiler stack (Clang/LLVM/GCC)  
- BPF/eBPF tools  
- Performance analysis tools  
- Additional utilities
